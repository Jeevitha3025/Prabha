Build a mobile-first React web app called PRABHA (प्रभा), an AI-guided entrepreneurship companion for rural Indian women. Use React (Vite) + Tailwind CSS. No external UI libraries, no icon libraries, no CDN fonts. Emoji are the icons. Assume the user is a rural woman with low literacy on a budget Android phone with slow internet. The app must feel voice-first, visual-first, and very simple.

IMPORTANT ARCHITECTURE RULES
This UI is a front-end shell. I will connect the AI backend afterwards, so:
1. Put ALL text in /src/i18n/translations.js as { en: {...}, hi: {...}, kn: {...} }. Components only use t('key'). Never hardcode display strings in components. Language can be changed at any time from the Profile screen and the top bar 🌐 button, and the whole UI updates instantly.
2. Put ALL data/AI calls in /src/services/api.js as async functions that currently return mock data after a short delay, each with a clear "// TODO: replace with real backend call" comment. Functions:
   sendOtp(phone), verifyOtp(phone, otp), createUser(profile),
   submitMentorDocuments(files, profile) -> {status:'pending'},
   getMentorStatus() -> 'pending' | 'approved' | 'rejected',
   getOpportunities(profile) -> 3 opportunities,
   getMentorsForUser(profile), getMentorRequests(), acceptMentorRequest(id),
   bookMentorSlot(mentorId, slot), getChatReply(message, history, lang),
   submitReadiness(answers) -> {score}, connectGoogleCalendar().
   Mock OTP for demo is 123456.
3. Put ALL voice logic in /src/hooks/useVoice.js exposing: startListening(lang, onResult), stopListening(), speak(text, lang), isListening, isSupported. Default implementation uses the browser Web Speech API (SpeechRecognition / speechSynthesis) with locale codes hi-IN, en-IN, kn-IN. If unsupported, hide the mic and show a small friendly text hint instead of failing. Keep this file swappable for a cloud STT/TTS provider later.
4. App state in a simple context: screen, lang, role, user, profile, opportunity, readinessScore. Persist lang, role, user, profile to localStorage. Use a simple screen-state router (no routing library).
